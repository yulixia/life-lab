# 人生实验室 UI 规范 V1.1

更新日期：2026-08-11

适用范围：人生实验室移动端 Web App 全部页面、状态与公共组件
唯一主题源：`src/styles/theme.css`

## 1. 目标与边界

人生实验室采用“清透柔光卡片风（Soft Pastel Glass UI）”。统一的是设计骨架，不统一各模块的主题皮肤。

本规范统一：

- 所有颜色、间距、字号、字重、行高、圆角、阴影和固定尺寸
- 页面骨架、内容密度、卡片结构和主次操作关系
- 今日、情绪能量、总库、实验、复盘、数据设置等功能的视觉规则
- 空状态、进行中、已记录、待复盘、禁用、错误和危险操作等状态
- 主题变量的命名、使用和逐页迁移方式

本规范不改变：

- 产品功能、字段、状态、路由和交互流程
- 7 天实践闭环及其业务判断
- 各模块现有主题配色和状态颜色含义
- 用户数据、默认数据和本地存储结构

## 2. 单一主题源原则

### 2.1 文件职责

`src/styles/theme.css` 是系统唯一允许保存固定视觉数值的文件，负责：

- 基础语义色
- Summer Pastel 75 色表
- 四个模块主题及正向/消耗子主题
- 表面色、描边色和装饰色
- 间距、字号、字重、行高、圆角和阴影
- 触控尺寸、图标尺寸、导航尺寸和进度尺寸
- 卡片、面板、按钮、标签等组件契约
- 尚未迁移页面使用的兼容变量

功能页面和组件样式文件只允许引用 `var(--token-name)`，不得重新写固定视觉数值。

### 2.2 页面样式允许保留的内容

页面和组件本地 CSS 可以定义：

- `display`、`position`、`grid`、`flex` 等结构关系
- `auto`、`1fr`、`minmax()`、`repeat()` 和 `100%` 等相对布局
- 无视觉含义的 `0`
- 内容状态选择器、响应式结构切换和可访问状态

页面和组件本地 CSS 不允许定义：

- HEX、RGB、RGBA、HSL 等颜色
- 固定 `px`、`rem` 字号、间距、圆角、阴影、图标尺寸和控件高度
- 自己的模块主题色、状态色或透明度
- 与 `theme.css` 重复的设计变量

CSS 自定义属性不能用于媒体查询条件，因此 `340px` 等断点可以在媒体查询中保留字面值，但必须同步登记在本规范中。

### 2.3 TypeScript 和 JSX 规则

- 迁移后的 Lucide 图标通过 CSS 类获取尺寸，不在 JSX 中写 `size={...}`。
- 业务数字，例如 7 天周期、能量分值和数据统计，不属于视觉主题变量。
- JSX 不得通过内联样式写主题颜色或固定视觉尺寸。
- 页面只能使用当前模块注入的 `--color-primary` 等语义别名，不直接引用其他模块主色。

## 3. 主题变量层级

主题变量分为五层：

1. **原始柔彩色**：`--summer-pastel-*`
2. **基础语义色**：`--color-heading`、`--color-ink`、`--color-danger` 等
3. **模块主题色**：`--theme-today-*`、`--theme-energy-*`、`--theme-library-*`、`--theme-data-*`
4. **设计基础变量**：间距、字号、圆角、阴影、尺寸
5. **组件契约变量**：卡片内边距、按钮高度、进度高度等

功能页优先使用第 5 层和第 2 层变量。只有模块外壳负责把第 3 层映射成当前页面的语义色。

### 5.2 模块注入方式

应用外壳根据当前路由设置模块主题，并统一映射为：

```css
--color-primary: var(--section-accent);
--color-primary-strong: var(--section-accent-strong);
--color-primary-soft: var(--section-accent-soft);
--color-focus: var(--section-accent-focus);
```

公共组件只使用这组语义别名，因此同一组件进入不同模块时自动继承对应配色。

## 8. 字体层级

| 变量 | 字号 | 默认字重 | 行高 | 用途 |
|---|---:|---:|---:|---|
| `--font-size-page` | `28px` | `750` | `1.25` | 页面标题 |
| `--font-size-card-title` | `20px` | `600` | `1.35` | 卡片和区块标题 |
| `--font-size-data` | `16px` | `600` | `1.35` | 周期天数、主要状态 |
| `--font-size-body` | `14px` | `400–500` | `1.5–1.6` | 正文、按钮、操作内容 |
| `--font-size-meta` | `13px` | `500` | `1.35` | 日期、辅助数据 |
| `--font-size-caption` | `12px` | `500` | `1.35` | 标签、字段名、导航 |

规则：

- 页面主要字号控制在六级以内。
- 不通过全粗体制造层级。

- 字间距固定为 `0`，字号不随视口宽度自动缩放。
- 任何可见文字不得小于 `12px`。

## 10. 公共组件规范

### 10.1 页面标题栏

- 上间距使用 `--layout-page-top`，下间距使用 `--layout-header-bottom`。
- 页面标题使用 `--font-size-page`，不超过 `--font-weight-bold`。
- 日期和辅助操作使用 `--font-size-meta` 与 `--color-label`。
- 返回按钮使用 `--tap-min` 和 `--radius-button`。

### 10.2 卡片

- 外圆角使用 `--radius-card-large`。
- 内边距使用 `--card-padding`，内部主间距使用 `--card-content-gap`。
- 背景使用 `--surface-card-standard` 或 `--surface-card-strong`。
- 阴影使用 `--shadow-card-soft`。
- 禁止卡片嵌套卡片；内部信息分区使用无外阴影面板。

### 10.3 信息面板

- 圆角使用 `--radius-panel`。
- 内边距使用 `--panel-padding-block` 和 `--panel-padding-inline`。
- 内部间距使用 `--panel-content-gap`。
- 背景从主题表面变量中选择，不写新透明色。

### 10.4 按钮

- 标准高度使用 `--button-height`，不得小于 `--tap-min`。
- 圆角使用 `--radius-button`。
- 水平内边距使用 `--button-padding-inline`。
- 双按钮使用 `--action-grid-columns`，次操作约占 `45%`，主操作约占 `55%`。
- 主按钮使用 `--primary-gradient` 和 `--primary-button-shadow`。
- 次按钮使用 `--surface-glass` 和 `--shadow-inset`。
- 完成按钮使用当前模块浅色表面，并移除外阴影。
- 一个操作区最多一个高强调主按钮。

### 10.5 标签与状态

- 高度使用 `--badge-height`，圆角使用 `--radius-pill`。
- 字号使用 `--font-size-caption` 或 `--font-size-meta`。
- 状态颜色跨页面保持一致，并同时显示文字。

状态映射：

| 状态 | 色位 |
|---|---|
| 待探索 | `--summer-pastel-10-05` |
| 进行中/完结 | `--summer-pastel-10-02` |
| 待复盘/结论 | `--summer-pastel-14-03` |
| 长期进行 | `--summer-pastel-12-01` |
| 终止 | `--summer-pastel-14-02` |
| 已归档/长期终止 | `--summer-pastel-04-03` |

### 10.6 表单控件

- 输入框、选择框、文本域最小高度使用 `--tap-min`。
- 控件圆角使用 `--radius-button`。
- 字段之间使用 `--space-12`。
- 聚焦轮廓使用 `--focus-ring-width`、`--focus-ring-offset` 和 `--color-focus`。
- 错误信息使用 `--color-danger`，不能只显示红色边框。

### 10.7 分段控件

- 外框使用 `--radius-panel`，内部选项圆角使用 `--radius-14` 的后续主题别名。
- 选中项使用当前模块浅色表面和主色文字。
- 文字必须完整显示；空间不足时换行或改用菜单。

### 10.8 底部导航

- 高度使用 `--nav-height`，入口高度使用 `--nav-item-height`。
- 图标使用 `--icon-size-nav`，文字使用 `--font-size-caption`。
- 整体圆角使用 `--radius-26`，选中项使用 `--radius-panel`。
- 每个入口的选中态继承对应模块主色和浅色表面。
- 页面底部使用 `--layout-page-bottom` 避免内容被遮挡。

### 10.9 弹窗与确认

- 遮罩使用 `--surface-overlay`。
- 弹窗表面使用 `--surface-card-strong`。
- 普通确认遵循当前模块色；删除确认必须使用危险语义色。
- 危险操作与普通操作之间使用独立分区和明确说明。

## 11. 功能页面覆盖

### 11.1 今日 `/today`

主题：今日。

| 状态/功能 | 布局与主题规则 |
|---|---|
| 有进行中实践 | 标签、标题、紧凑七日进度、双列行动面板、主次操作 |
| 已记录 | 主按钮变为浅青完成态，文案为“今天已记录 ✓” |
| 未记录 | 次按钮“标记未实践”，主按钮“记录今日” |
| 明日开始 | 进度全部为未来态，操作区显示中性等待状态 |
| 待复盘 | 显示方向、状态、周期说明和唯一主入口“去复盘” |
| 空方向 | 使用普通卡片和“去总库”入口，不使用高强调主按钮 |
| 长期事项 | 独立区块，活动事项显示今日入口，终止事项显示说明 |

七日进度规则：

- 面板使用 `--surface-progress`。
- 当前天使用 `--primary-gradient`。
- 已经过日期使用 `--progress-complete-background`。
- 未来日期使用 `--surface-control-strong`。
- 进度段高度和间距使用主题变量。

### 11.2 情绪能量总览 `/energy`

主题：情绪能量。

- 页面标题、主要入口和导航使用情绪模块主题。
- “有能量”和“被消耗”分别使用各自子主题，不能互换。
- 总览数据使用 `--font-size-data`，说明使用 `--font-size-meta`。
- 最近记录采用可扫描列表，不堆叠大型卡片。
- 高频标签使用固定状态色，颜色之外必须保留标签文字。
- 空状态保留新增记录的唯一主入口。

### 11.3 情绪记录新增/编辑 `/energy/new`、`/energy/:entryId/edit`

- 分类选择使用分段控件，切换后注入对应子主题。
- 能量刻度、标签选择、文本域和提交按钮全部继承当前子主题。
- 混合感受保留产品逻辑，视觉上使用两个子主题的明确分区。
- 表单字段间距使用 `--space-12`，主要分组间距使用 `--space-24`。
- 底部只保留一个提交主按钮。

### 11.4 情绪记录详情 `/energy/:entryId`

- 使用记录所属的有能量/被消耗子主题。
- 事件、原因、感受、观察按无阴影信息面板分组。
- 编辑为普通操作，删除进入危险操作区并二次确认。

### 11.5 总库 `/library`

主题：总库。

- 筛选和方向切换使用紫色主题分段控件。
- 列表卡片按标签、标题、状态、摘要、当前周期和操作顺序组织。
- 状态色使用统一状态映射，不根据筛选条件换色。
- 列表内容密集时使用 `--font-size-body` 和 `--font-size-meta`，不缩小到 `12px` 以下。
- 新建事项是页面唯一高强调主操作。
- 空筛选结果与系统无事项使用不同文案，但共享空状态组件。

### 11.6 事项新建/编辑 `/items/new`、`/items/:itemId/edit`

- 继承总库主题。
- 方向、标题、描述等字段采用统一表单节奏。
- 固定选项优先使用分段控件或菜单，不堆叠文本按钮。
- 保存是唯一主按钮，取消/返回为次操作。
- 删除不出现在新建表单中；编辑页删除必须进入危险分区。

### 11.7 事项详情 `/items/:itemId`

- 继承总库主题和事项状态色。
- 顶部显示方向标签、事项标题和状态。
- 当前周期、历史周期和事项说明使用无嵌套卡片的分区结构。
- 开始实践、继续记录或去复盘根据业务状态成为唯一主操作。
- 编辑、归档、终止和删除进入低频操作或危险分区。

### 11.8 新建 7 天实践 `/items/:itemId/experiments/new`

- 继承总库主题，周期执行状态进入今日页后使用今日主题。
- 行动计划和达标线使用并列语义信息，但表单中保持纵向填写。
- 日期、轨道占用和校验提示靠近对应字段。
- 创建实践是唯一主按钮。

### 11.9 今日记录 `/experiments/:cycleId/check-in`

主题：今日。

- 已实践/未实践使用分段控件，不改变原有判断逻辑。
- 已实践状态突出行动总结；未实践状态突出原因和观察。
- 日期和周期信息使用紧凑状态面板。
- 保存记录是唯一主按钮，完成后进入浅青完成态。

### 11.10 周期复盘 `/experiments/:cycleId/review`

主题：今日，状态标签沿用事项状态色。

- 事实、感受、发现、决定分成连续区块，不使用卡片嵌套。
- 五种决定保持原业务含义，使用统一选择控件。
- 决定造成的状态变化必须同时用文字说明。
- 提交复盘是唯一主按钮；不可逆决定需要确认。

### 11.11 长期事项记录

主题：今日。

- 今日入口与普通实践并列，但视觉权重低于 7 天重点实践。
- 已完成使用浅色完成态，终止状态只显示说明和详情入口。
- 备注输入沿用表单组件，不创建独立颜色体系。

### 11.12 数据与设置 `/settings`

主题：数据与设置。

- 数据摘要使用浅绿色主题，不与危险操作混色。
- 导出、导入和本地数据说明使用普通操作区。
- 删除全部数据单独放在危险操作区，使用 `--color-danger`。
- 本地存储异常使用错误组件，并提供可恢复的导出入口。
- 首次本地数据提示使用统一确认弹窗。

### 11.13 系统状态

| 状态 | 规则 |
|---|---|
| 加载 | 使用中性表面和简短状态文字，不使用模块主按钮 |
| 空状态 | 说明原因并提供最多一个主入口 |
| 保存失败 | 紧邻操作区显示错误，不清空用户输入 |
| 数据损坏 | 停止正常加载，提供原始数据导出 |
| 禁用 | 保留文字可读性，不只降低透明度 |
| 焦点 | 使用当前模块 `--color-focus` |
| 危险 | 使用危险语义色并二次确认 |

## 12. 响应式与无障碍

- 支持 `320–430px` 移动端宽度，桌面端最大 `430px` 居中。
- 主要断点为 `340px`：双列行动面板和双按钮在此以下改为单列。
- 所有交互目标不小于 `44 × 44px`。
- 正文行高不小于 `1.5`。
- 焦点状态必须可见，不能只依赖阴影。
- 文字、图标和动态内容不得重叠或溢出。
- 长按钮文字允许换行，不通过缩小字号解决。
- 状态必须同时包含文字，不以颜色作为唯一线索。
- 页面固定导航和操作区必须处理安全区域。

## 13. 逐页迁移步骤

每次只迁移一个页面或一个公共组件，按以下顺序执行：

1. 列出页面现有固定颜色、尺寸、间距、圆角和阴影。
2. 将可复用值映射到 `theme.css` 现有变量。
3. 缺少变量时先在 UI 规范中确认含义，再新增主题变量。
4. 页面 CSS 替换为主题变量，禁止保留固定视觉数值。
5. JSX 中的图标尺寸迁移到 CSS 类。
6. 检查正常、空、加载、禁用、错误和完成状态。
7. 检查 `320px`、`340px` 和 `430px` 宽度。
8. 运行类型检查、测试和正式构建。
9. 确认页面业务逻辑和模块配色未改变。

禁止一次性机械替换所有页面。每个页面在优化时同时完成视觉确认和主题迁移。
